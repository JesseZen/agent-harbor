# Triage labels

| Canonical role | Tracker label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer needs to evaluate the issue |
| needs-info | needs-info | Waiting for information needed to proceed |
| ready-for-agent | ready-for-agent | Fully specified for agent implementation; blockers still apply |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

Skills use the tracker label in this table when they refer to a canonical role. Change the mapping here if the repository adopts different names.
